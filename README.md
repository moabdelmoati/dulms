# Delta University (DULMS) Course Availability Checker Bot

بوت تليجرام آلي لفحص بوابة جامعة الدلتا (DULMS) ومراقبة المقاعد الشاغرة والمواد المفتوحة للتسجيل كل 30 دقيقة عبر **GitHub Actions** على مدار 24 ساعة.

## الميزات
- تسجيل دخول تلقائي وآمن لبوابة جامعة الدلتا.
- جلب الساعات المسموحة والمدفوعة والمسجلة والأيام المتبقية.
- فحص المقاعد في كل مجموعة (Group) وحالة التسجيل (مفتوح / مكتمل / مغلق).
- تنبيه فوري ومباشر على تليجرام عند فتح أي مقعد شاغر.
- تشغيل سحابي مجاني 24/7 عبر GitHub Actions دون الحاجة لفتح الكمبيوتر.

## المتغيرات المطلوبة في GitHub Secrets
- `STUDENT_ID`
- `STUDENT_PASS`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
